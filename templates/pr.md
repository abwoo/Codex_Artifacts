# Review Walkthrough

## Change Summary

Describe the change in one paragraph, then call out the files, commands, or behaviors that matter most.

## Diff Notes

```diff
+ Add the important positive path here.
- Remove stale behavior here.
```

## Review Risks

| Risk | Severity | Mitigation |
| --- | --- | --- |
| Missing test coverage | Medium | Add focused verification before merging. |
| Hidden coupling | Low | Link the affected code paths in the notes. |

## Suggested Review Order

1. Read the intent summary.
2. Inspect the diff notes.
3. Run the verification commands.
